# Моя документация

Это мой первый документационный проект в подходе Docs as Code.

## О проекте

Документация хранится в Git и создаётся с помощью MkDocs. Исходники пишутся в Markdown, сайт собирается одной командой, а история правок видна в истории коммитов.

## Возможности

- Markdown
- Git
- GitHub
- MkDocs

## Документируемый проект

В качестве сквозного кейса выбран ИИ-проект: чат-бот, который отвечает в групповом чате как ещё один участник беседы. Подробности в разделе [Проект](project/overview.md).
