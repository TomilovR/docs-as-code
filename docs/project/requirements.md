# Требования

## User Stories

### US-01. Ответ бота на сообщение

Как участник чата,
я хочу получать от бота короткий и уместный ответ на своё сообщение,
чтобы беседа выглядела естественно.

Критерии приёмки:

- бот принимает текстовое сообщение из чата;
- в ответ он отправляет текстовое сообщение;
- если подходящих примеров найти не удалось, бот всё равно отвечает, используя запрос без примеров.

### US-02. Просмотр выбранных примеров

Как разработчик,
я хочу видеть, какие примеры реранкер выбрал для запроса к LLM,
чтобы понимать, почему бот ответил именно так.

Критерии приёмки:

- в режиме отладки выводится список выбранных примеров;
- рядом с каждым примером показана оценка реранкера;
- примеры отсортированы по убыванию оценки.

### US-03. Оценка качества реранкера

Как разработчик,
я хочу запускать оценку реранкера на тестовой выборке,
чтобы сравнить его с простым базовым решением (BM25).

Критерии приёмки:

- команда оценки считает метрики Recall@1, Recall@5, MRR и NDCG@10;
- те же метрики считаются для бейзлайна BM25;
- результаты можно сравнить в одной таблице.

## Use Case

### UC-01. Ответ на сообщение в чате

**Актор:** участник чата.

**Цель:** получить от бота ответ на своё сообщение.

**Предусловие:** бот добавлен в чат, модели и индекс реплик загружены.

**Основной сценарий:**

1. Участник пишет сообщение в чат.
2. Бот передаёт текст сообщения сервису.
3. Сервис находит среди сохранённых реплик 50 кандидатов поиском BM25.
4. Сервис передаёт пары «сообщение и кандидат» реранкеру (ML-модели).
5. Реранкер возвращает оценку для каждой пары.
6. Сервис выбирает 5 лучших примеров и убирает из них нежелательные.
7. Сервис формирует запрос к LLM с этими примерами и отправляет его.
8. LLM возвращает текст ответа.
9. Бот отправляет ответ в чат, участник видит его.

**Альтернативный сценарий:**

- Если реранкер недоступен, сервис использует 5 первых кандидатов из BM25.
- Если LLM не ответила за отведённое время, бот ничего не пишет в чат и записывает ошибку в журнал.

**Результат:** ответ отправлен в чат, либо бот сознательно промолчал и сбой записан в журнал.
