# Чат-бот с реранкером реплик

Сервис отвечает на сообщения в групповом чате Telegram так, как мог бы ответить ещё один участник беседы, а не ассистент. Ответ пишет готовая языковая модель (LLM), а в её запрос добавляются несколько реальных примеров вида «сообщение и ответ на него». Лучшие примеры выбирает обученная модель-реранкер: она оценивает, насколько каждая реплика подходит как естественный ответ на входное сообщение.

Основные пользователи:

- участник чата;
- разработчик (обучает и оценивает реранкер, настраивает бота).

Основные функции:

- ответ бота на сообщение в чате;
- подбор примеров для запроса к LLM с помощью реранкера;
- оценка качества реранкера на тестовых данных.

## Комплект документации

Для проекта потребуются следующие документы и разделы:

1. **Описание проекта.** Для новых участников команды и заинтересованных сторон: что за система и зачем она нужна.
2. **Требования.** Для разработчиков и тестировщиков: User Stories, критерии приёмки и Use Case, по которым проверяется результат.
3. **Архитектура системы.** Для разработчиков: из каких компонентов состоит система и как они взаимодействуют.
4. **Документация ML-модели (реранкер).** Для ML-инженеров: данные обучения, метрики, ограничения и способ обучения модели.
5. **Описание данных.** Для ML-инженеров: источник датасета, его лицензия и известные проблемы (шум, перекос по чатам, чувствительное содержание).
6. **Руководство по запуску.** Для разработчиков: как настроить окружение, обучить модель и запустить предсказание.
7. **Руководство пользователя.** Для участников чата: как общаться с ботом и чего от него ожидать.
