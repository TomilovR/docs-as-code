# Data Sheet

Для обучения bge-reranker-v2-m3 в карточке модели названа смесь многоязычных данных (bge-m3-data, обучающие части Quora и FEVER), но подробно эти наборы там не описаны. Поэтому здесь описан открытый датасет, на котором модель будет оцениваться и при необходимости дообучаться в нашем проекте.

## Общая информация

**Название датасета:**  
Russian dataset for the reply recovery

**Источник:**  
[Mendeley Data](https://data.mendeley.com/datasets/xm86yszck2/1), автор Igor Buyanov, 2023, DOI 10.17632/xm86yszck2.1. Лицензия CC BY 4.0.

**Назначение:**  
Восстановление ответа: определить, является ли одна реплика ответом на другую.

## Состав данных

**Объём:**  
Около 60 МБ. Разбиение авторов: train - 797 701 строка, eval - 88 606, test - 8 690.

**Тип данных:**  
Текст на русском языке, пары реплик из чатов Telegram.

**Основные поля / признаки:**  
`premise` (сообщение), `hypothesis` (реплика-кандидат), `label` (метка пары), `chat` (из какого чата пара).

## Получение данных

Пары собраны из девяти русскоязычных чатов Telegram разной тематики (футбол, соседи, молодые мамы, эмигранты, геймеры и другие). Положительные пары взяты по настоящей разметке ответа `reply_to` в Telegram, отрицательные подобраны случайно. Тестовая часть размечена краудсорсингом и проверена авторами.

## Предобработка

Предобработка у авторов: не указано.

Предобработка в нашем проекте (не часть исходного датасета):

- метки инвертированы относительно ожидаемых (настоящий ответ имеет метку 0), поэтому они переворачиваются;
- исключается чат `chat_suicidnikov` с опасным содержанием;
- из реплик удаляются телефоны и ссылки, мат отфильтровывается перед подстановкой примеров в запрос к LLM;
- для обучения к случайным негативам добавляются трудные негативы, найденные BM25.

## Ограничения

- **Нет контекста:** только пара «сообщение и ответ», без предыдущих реплик, авторов и времени. Часть пар без контекста непонятна, около 29% ответов короче 15 символов.
- **Перекос по чатам:** в train около 46% строк из одного игрового чата, чат программистов почти не представлен (362 строки).
- **Шумные негативы:** случайно подобранная реплика иногда тоже подходит как ответ.
- **Чувствительное содержание:** реальные переписки содержат личные сведения и токсичные высказывания.

## Использование в проекте

- Из пар датасета строится база реплик, в которой BM25 ищет кандидатов, а реранкер выбирает примеры для LLM.
- Тестовая часть используется для сравнения реранкера с BM25 (US-03): для каждого сообщения формируется пул из настоящего ответа и 99 кандидатов.
- Обучающая часть используется для дообучения реранкера, если готовой модели не хватит.
